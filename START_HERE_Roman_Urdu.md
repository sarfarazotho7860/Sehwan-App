# Sehwan Connect — Free starter

Jani, yeh ready prototype files hain. Abhi yeh **demo** hai, full live app nahi. Listings sample hain aur forms ka data server par save nahi hota.

## Sab se asaan tareeqa (free)
1. ZIP ko download karein aur unzip/extract karein.
2. Is folder mein `index.html` file hai.
3. Agar laptop hai, `index.html` par double-click karke browser mein demo dekh sakte hain.
4. Isay internet par free publish karne ke liye GitHub account aur GitHub Pages setup karna hoga. Iske liye account owner ko khud sign-in karna padega; main aapke account mein login nahi kar sakta.
5. iPhone par app jaisi install karne ke liye published website Safari mein khol kar Share > Add to Home Screen use kiya ja sakta hai.

## Abhi kya chalta hai?
- Sehwan Sharif/Karampur area toggle
- Search aur category filters
- Demo listings dekhna
- Demo listing form (sirf current page session mein)
- Responsive mobile layout

## Abhi kya nahi chalta?
- Real account/login
- Online database / admin backend
- Real verified businesses or phone numbers
- Real orders, payments, delivery dispatch
- App Store / Play Store publishing

## Important
Sample phone numbers aur businesses placeholders hain. Public launch se pehle unko verified local listings se replace karna zaroori hai. Free hosting/service plans ki limits hoti hain.
